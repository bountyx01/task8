# Задание 3

Разработана система из workbench и db, позволяющая работать с таблицами sectors, hosts, teams, reports произвольного кибериспытания Stand.Off

В `tools/` доступны файлы для развертывания, генерации env, сброса проекта

В `workbench/` доступен код приложения, с помощью которого производится работа

В `postgres/` доступны файлы конфигурации postgres.
